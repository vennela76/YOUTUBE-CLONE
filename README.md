

## Ventube — Video Sharing Website

This is a responsive front-end clone of a video sharing platform similar to YouTube. Users can navigate, search, and play videos in a visually appealing interface.

### Project Structure

```
ventube/
├── index.html           # Homepage showing video thumbnails
├── play-video.html      # Video player page
├── script.js            # Interactive JavaScript (navigation, search, comments)
├── style.css            # Stylesheet (not uploaded yet)
├── video.mp4            # Sample video
├── [images & icons]     # UI images like logo, thumbnails, profile icons (not bundled yet)
```

---

### How to Run

1. Place all files in the same directory.
2. Replace all absolute image paths (e.g., `C:\Users\hp\Desktop\ventube\logo.png`) with relative paths like `images/logo.png`.
3. Open `index.html` in your browser to start.

---

### Features

- Search box (basic alert-based implementation)
- Video playback with `video.mp4`
- Sidebar toggle with menu icon
- Comment input (static demo)
- Like and Dislike buttons (basic interaction)
- Responsive layout using Flexbox
